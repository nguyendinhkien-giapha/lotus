LOTUS V1.34 – ĐÃ TÍCH HỢP LOGO VÀ ICON
- Thay logo hoa sen nét cũ ở đầu website bằng icon hoa sen mới nền xanh.
- Giữ chữ LOTUS bên cạnh logo trên thanh tiêu đề website.
- Thêm favicon cho tab trình duyệt.
- Thêm apple-touch-icon 180x180 để iPhone dùng khi chọn "Thêm vào Màn hình chính".
- Thêm manifest và icon 192/512 cho hỗ trợ cài đặt dạng ứng dụng.

CÁCH CẬP NHẬT GITHUB PAGES
1. Giải nén ZIP.
2. Mở thư mục LOTUS_V1.34.
3. Tải toàn bộ các tệp bên trong lên thư mục gốc repository đang xuất bản website (cùng cấp index.html).
4. Ghi đè index.html cũ và thêm các tệp icon/manifest mới.
5. Chờ GitHub Pages triển khai xong rồi mở lại website.
6. Trên iPhone: mở bằng Safari > Chia sẻ > Thêm vào Màn hình chính.

Nếu iPhone vẫn giữ icon cũ, xóa shortcut cũ khỏi Màn hình chính rồi thêm lại sau khi tải mới website.
